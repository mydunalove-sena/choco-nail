# 쵸코네일 v1 사용자 요구사항 정리

| ID | 요구사항 | 분류 | 구현 상태 | 근거 | 비고 |
|---|---|---|---|---|---|
| UR-001 | 매장명과 기본 정보 제공 | 콘텐츠 | 구현 | [확정] `index.html`, 각 카테고리 HTML의 title, brand, hero 영역에 `쵸코네일 삼송점`이 표시된다. | 상세 영업시간, 전화번호 등은 코드에서 직접 확인되지 않는다. |
| UR-002 | PC 화면 제공 | 화면 | 구현 | [확정] `index.html`의 `.hero`, `.hero-frame`, `images/final-design.png` 기반 PC 랜딩이 있다. 카테고리 페이지도 `.site-header`, `.page-hero`, 카드 그리드 구조가 있다. | PC 메인 원본 디자인은 이미지 기반이다. |
| UR-003 | 모바일 화면 제공 | 반응형 | 구현 | [확정] `index.html`의 `.mobile-home`, 카테고리 페이지의 모바일 헤더/히어로, `category-style.css`의 760px 이하 모바일 CSS가 있다. [이력 확인] 모바일 레이아웃 추가 커밋들이 존재한다. | PC와 모바일을 별도 섹션으로 운영한다. |
| UR-004 | 젤네일 페이지 이동 | 기능 | 구현 | [확정] `index.html` 상단 메뉴와 하단 서비스 버튼이 `gel-nail.html`로 연결된다. 카테고리 nav에도 네일 링크가 있다. | `gel-nail.html`에 이미지 카드 목록이 있다. |
| UR-005 | 패디 페이지 이동 | 기능 | 구현 | [확정] `index.html`과 카테고리 nav에서 `pedi.html`로 이동한다. | 화면 표기는 `패디`로 통일하는 것을 기준으로 하며, 다른 표기가 남아 있는지는 추가 확인이 필요하다. |
| UR-006 | 이달의 아트 페이지 이동 | 기능 | 구현 | [확정] `index.html`과 카테고리 nav에서 `monthly-art.html`로 이동한다. | 추천 아트 이미지 목록이 있다. |
| UR-007 | 시술 이미지·리뷰 페이지 이동 | 기능 | 구현 | [확정] `index.html`의 리뷰 링크와 카테고리 nav가 `gallery.html`로 연결된다. `gallery.html`의 title과 화면명은 `리뷰`다. | 메인 메뉴 표기는 리뷰이고 연결 페이지는 `gallery.html`이며, 최종 명칭 통일은 확인 필요하다. |
| UR-008 | 매장소개 페이지 이동 | 기능 | 구현 | [확정] `index.html`과 카테고리 nav에서 `shop.html`로 이동한다. | `shop.html`은 매장 소개 및 오시는 길 안내 이미지를 제공한다. |
| UR-009 | 네이버 예약 링크 | 외부 연결 | 구현 | [확정] 홈, 카테고리, 케어, 리뷰, 매장 소개 페이지에서 `https://map.naver.com/p/entry/place/1964980021` 링크를 사용한다. | 네이버 예약 링크 주소는 확인되었으며, 각 페이지의 새 창 열기 속성 적용 여부와 일관성은 별도 요구사항에서 확인한다. |
| UR-010 | 카카오톡 상담 링크 | 외부 연결 | 구현 | [확정] `index.html` PC/모바일 영역에 `https://open.kakao.com/o/sCU8pFob` 링크가 있다. | 현재 확인 기준으로 홈에 집중되어 있다. |
| UR-011 | 네이버 블로그 링크 | 외부 연결 | 구현 | [확정] `index.html` PC/모바일 영역에 `https://blog.naver.com/boong27` 링크가 있다. | 현재 확인 기준으로 홈에 집중되어 있다. |
| UR-012 | 서비스별 이미지 제공 | 콘텐츠 | 구현 | [확정] `gel-nail.html`은 `images/nail_*.jpg`, `pedi.html`은 `images/pedi_*.jpg`, `monthly-art.html`은 `images/art_*.jpg`, 케어/리뷰/매장 소개 관련 이미지가 `images/`에 있다. | 이미지 파일 연결은 구현되었으며, HTML의 alt 속성 존재 여부, 설명 적절성, 일관성은 별도 QA가 필요하다. |
| UR-013 | 모바일 주요 메뉴 제공 | 기능 | 구현 | [확정] 홈 모바일에는 `.mobile-service-menu`가 있고, 카테고리 페이지에는 `details` 기반 모바일 메뉴가 있다. | 홈 모바일 메뉴는 네일, 이달의 아트, 패디, 케어 중심이다. |
| UR-014 | 주차 가능 정보 제공 | 콘텐츠 | 일부 구현 | [확정] `index.html` 모바일 특징 영역에 `주차 가능` 문구가 있다. | 모바일 특징 영역의 `주차 가능` 문구는 확인되었으며, PC 원본 이미지의 주차 정보 표시 여부는 별도 육안 확인이 필요하다. |
| UR-015 | 케어 페이지 제공 | 콘텐츠 | 구현 | [확정] `care.html`이 존재하고, 메뉴에서도 `care.html`로 연결된다. 손 케어, 물어뜯는 손톱 케어, 손톱 연장, 맨즈 손 케어, 내성 발톱 케어, 무좀 발톱 케어, 홀드펀칭 항목이 있다. | 유지 여부는 별도 의사결정 필요. |
| UR-016 | 외부 링크를 새 창으로 열기 | 외부 연결 | 구현 | [확정] 네이버 예약, 카카오톡 상담, 블로그, 리뷰 등 주요 외부 링크는 새 창으로 열리고 rel 속성이 적용되어 있다. | 링크별 rel 값의 일관성은 별도 QA가 필요하다. |
| UR-017 | PC 원본 구조를 유지하면서 모바일 화면 보완 | 반응형 | 구현 | [확정] PC 홈은 `images/final-design.png`와 hotspot 구조를 유지한다. 모바일에서는 `.hero`를 숨기고 `.mobile-home`을 표시한다. [이력 확인] 모바일 레이아웃 추가 커밋들이 분리되어 있다. | v1의 핵심 구현 방식으로 볼 수 있다. |
