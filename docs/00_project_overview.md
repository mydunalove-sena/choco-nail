## 2. 프로젝트 목적

- [추정] 쵸코네일 삼송점의 기본 정보와 서비스 이미지를 메인 화면과 서비스별 개별 페이지를 통해 확인하고, 예약·상담·블로그로 이동할 수 있도록 만든 소규모 매장 홈페이지다.
- [확정] 메인 화면에서 네이버 예약, 카카오톡 상담, 네이버 블로그, 젤네일, 패디, 이달의 아트, 케어, 리뷰, 매장 소개 페이지로 이동할 수 있다.
- [확정] 각 카테고리 페이지는 서비스별 이미지와 간단한 설명을 제공한다.

## 3. 대상 매장과 사용자 구분

- [확정] 프로젝트 작업 범위: 기획 방향 정리, 정보 구조 정리, 화면과 문구 검수, 수정 요청 정리, AI 도구를 활용한 HTML/CSS 파일 수정, GitHub 이력 관리

## 5. v1의 핵심 특징

- [확정] PC 메인 화면은 `images/final-design.png` 원본 디자인 이미지를 `index.html`에서 배치하고, 투명한 클릭 영역을 겹쳐 링크를 제공하는 구조다.
- [확정] 모바일 메인 화면은 PC 원본 이미지를 그대로 축소하지 않고 `main.mobile-home`으로 별도 구성되어 있다.
- [확정] 카테고리 페이지는 `category-style.css`를 공통 스타일로 사용하며, 각 페이지에 PC용 헤더와 모바일용 헤더/히어로 영역이 함께 들어 있다.
- [확정] 외부 연결은 네이버 장소 URL, 카카오톡 상담, 네이버 블로그 중심으로 구성되어 있다.
- [확정] 리뷰 메뉴는 외부 네이버 리뷰가 아니라 내부 `gallery.html` 페이지로 연결된다.
- [확인 필요] 예약 버튼은 네이버 장소 URL에 연결되어 있으며, 실제 예약 화면으로 연결되는지는 매장주 확인이 필요하다.
- [확정] 서비스 이미지는 로컬 `images/` 폴더의 정적 이미지 파일을 참조한다.

## 6. PC 원본 디자인과 별도 모바일 화면 운영 구조

- [확정] `index.html`의 PC 영역은 `.hero`와 `.hero-frame`으로 구성되며, `images/final-design.png` 위에 `.hero-hotspot` 링크를 배치한다.
- [확정] `style.css`에서 `@media (max-width: 760px)` 조건일 때 `.hero`를 숨기고 `.mobile-home`을 표시한다.
- [확정] 젤네일, 패디, 이달의 아트, 케어, 리뷰, 매장 소개 페이지도 760px 이하에서 PC용 `.site-header` 또는 `.page-hero`를 숨기고 모바일 전용 헤더/히어로를 표시하는 CSS가 적용되어 있다.
- [추정] v1은 PC 원본 디자인의 시각적 형태를 유지하면서 모바일 접근성을 보완하는 방향으로 정리된 버전이다.

## 7. 주요 페이지 구성

| 페이지 | 파일 | 주요 내용 |
|---|---|---|
| 홈 | `index.html` | PC 원본 이미지형 랜딩, 모바일 전용 홈, 예약/상담/블로그/서비스 링크 |

| 케어 | `care.html` | 손·발톱 케어 소개, 케어 메뉴, 추천 대상, 진행 순서, 안내사항 |
