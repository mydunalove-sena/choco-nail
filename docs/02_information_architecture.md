# 쵸코네일 덕양삼송점 홈페이지 v1 정보 구조

## 1. 문서 목적

- [확정] 이 문서는 쵸코네일 홈페이지 v1의 페이지, 메뉴, 콘텐츠, 내부/외부 이동 관계를 현재 코드 기준으로 정리한 역기획 정보 구조 문서다.
- [확정] 기준 파일은 `index.html`, `gallery.html`, `gel-nail.html`, `monthly-art.html`, `pedi.html`, `care.html`, `shop.html`이다.
- [확정] PC 원본 화면 구조와 모바일 보완 구조를 함께 기록한다.
- [확정] HTML, CSS, JavaScript, 이미지 파일은 수정하지 않고 정보 구조만 문서화한다.
- [확정] 공식 프로젝트 표기는 쵸코네일 덕양삼송점이다.
- [확정] 현재 v1 화면 코드에는 주로 쵸코네일 삼송점이 표시된다.
- [확인 필요] 실제 화면 상호명 통일 여부는 별도 확인이 필요하다.

## 2. 전체 사이트맵

```text
[확정] index.html 홈
├─ [확정] gel-nail.html 젤네일 / 네일
├─ [확정] pedi.html 패디 / 페디
├─ [확정] monthly-art.html 이달의 아트
├─ [확정] care.html 케어
├─ [확정] gallery.html 리뷰
└─ [확정] shop.html 매장 소개
```

- [확정] 위 7개 HTML 파일은 실제 파일로 존재한다.
- [확정] `index.html` PC 영역의 투명 핫스팟 메뉴는 홈, 젤네일, 패디, 이달의 아트, 케어, 리뷰, 매장 소개로 연결된다.
- [확정] `index.html` 모바일 서비스 메뉴는 네일, 이달의 아트, 패디, 케어 4개만 노출한다.
- [확정] 하위 페이지의 PC/모바일 내비게이션은 홈, 네일, 패디/페디, 이달의 아트, 케어, 리뷰, 매장 소개를 노출한다.
- [확정] 리뷰 메뉴는 외부 네이버 리뷰가 아니라 내부 `gallery.html`로 연결된다.
- [확인 필요] `패디`와 `페디` 표기가 파일별로 혼재한다.

## 5. gallery.html 정보 구조

- [확정] `gallery.html`의 문서 제목과 내비게이션 표기는 `리뷰`다.
- [확정] 다른 페이지의 리뷰 메뉴는 내부 `gallery.html`로 이동한다.
- [확정] `gallery.html` 내부에는 리뷰 안내 포스터 이미지 `images/review_intro_poster.png`가 있다.
- [확정] `gallery.html`에는 네일/패디/아트처럼 여러 이미지 카드 그리드가 확인되지 않는다.
- [확정] 리뷰 포스터 위의 투명 링크와 모바일 히어로 버튼은 네이버 장소의 review 경로가 포함된 URL로 새 창 이동한다.
- [확정] `gallery.html`은 외부 네이버 리뷰 페이지 자체가 아니라 내부 리뷰 안내 페이지다.
- [추정] 현재 역할은 "전체 갤러리"보다는 "리뷰 안내 및 네이버 리뷰 이동"에 가깝다.
- [확인 필요] 메뉴명을 계속 `리뷰`로 유지할지, 파일명에 맞춰 `갤러리`로 정리할지 확인이 필요하다.
- [확정] PC에서는 `.page-hero`와 리뷰 포스터가 보이고, 모바일에서는 별도 모바일 헤더/히어로가 추가로 표시된다.

## 7. 모바일 내비게이션

- [확정] 홈 모바일은 `.mobile-home` 안에 브랜드/예약 헤더, 주요 링크 버튼, 서비스 메뉴를 가진다.
- [확정] 홈 모바일 서비스 메뉴는 네일, 이달의 아트, 패디, 케어만 노출한다.
- [확정] 홈 모바일에는 리뷰와 매장 소개로 가는 서비스 메뉴 링크가 확인되지 않는다.
- [확정] 하위 페이지 모바일은 `details` 기반 메뉴로 홈, 네일, 페디/패디, 이달의 아트, 케어, 리뷰, 매장 소개를 제공한다.
- [확정] 하위 페이지 모바일에는 현재 페이지에 `active` 및 `aria-current="page"`가 적용된다.
- [확정] CSS 기준 760px 이하에서 홈의 PC `.hero`는 숨겨지고 `.mobile-home`이 표시된다.
- [확정] CSS 기준 760px 이하에서 하위 페이지의 PC `.site-header`와 `.page-hero`는 숨겨지고 모바일 헤더/히어로가 표시된다.
- [확정] 모바일 예약 링크는 네이버 장소 URL로 새 창 이동한다. `gallery.html` 모바일 리뷰 버튼은 review 경로가 포함된 네이버 장소 URL로 이동한다.
