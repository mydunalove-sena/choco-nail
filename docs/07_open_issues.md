# 쵸코네일 v1 오픈 이슈

## 1. 케어 페이지 유지 여부

- [확정] 현재 v1에는 `care.html` 파일이 존재한다.
- [확정] `index.html`의 PC 상단 메뉴와 하단 서비스 버튼에서 `care.html`로 이동하는 링크가 있다.
- [확정] `index.html` 모바일 서비스 메뉴에도 `케어` 링크가 있다.
- [확정] 젤네일, 패디, 이달의 아트, 리뷰, 매장 소개 페이지의 PC/모바일 메뉴에도 `care.html` 링크가 포함되어 있다.
- [확정] `care.html`에는 손·발톱 케어 소개, 케어 메뉴, 추천 대상, 진행 순서, 안내사항이 구현되어 있다.
- [확인 필요] 케어 메뉴를 v1에서 계속 노출할지 매장주와 추후 협의가 필요하다.

## 2. 선택안

1. [확인 필요] 현재 상태로 유지
   - 메뉴와 `care.html`을 모두 유지한다.
   - 현재 구현과 가장 차이가 적다.

2. [확인 필요] 메뉴에서만 숨기고 페이지는 보존
   - 사용자에게 보이는 메뉴에서는 케어를 제거한다.
   - `care.html` 파일은 남겨 두어 추후 재노출 또는 v2 검토에 활용한다.

3. [확인 필요] 메뉴와 페이지 모두 제거
   - 메뉴 링크와 `care.html`을 모두 제거한다.
   - 관련 이미지, CSS, 문구까지 정리할지 별도 범위 확인이 필요하다.

## 3. 결정 전 원칙

- [확정] 현재 구현에는 케어 메뉴와 페이지가 실제로 존재한다.
- [확인 필요] 매장주와 유지/숨김/제거 방향이 정해지기 전까지 임의로 수정하지 않는다.
- [확인 필요] 케어 서비스가 실제 운영 메뉴인지, 상담 가능 범위가 어디까지인지 확인이 필요하다.
- [확인 필요] 의료적 오해를 줄이기 위한 문구 검수 여부도 확인이 필요하다.

## 4. 향후 확인이 필요한 매장 정보

- [확정] 현재 배포 주소: `https://mydunalove-sena.github.io/choco-nail/`
- [확인 필요] 영업시간, 휴무일, 전화번호 등 상세 매장 정보의 공개 범위
- [확인 필요] 주차 가능 정보의 정확한 안내 문구와 노출 위치
- [확인 필요] `페디`와 `패디` 표기 중 최종 사용할 표기
- [확인 필요] 별도 도메인 연결 또는 운영 주소 변경 여부
- [확인 필요] 네이버 예약, 카카오톡 상담, 네이버 블로그 링크가 실제 운영 링크로 확정되었는지 여부
- [확정] 리뷰 메뉴는 외부 네이버 리뷰가 아니라 내부 `gallery.html` 페이지로 연결된다.
- [확인 필요] 리뷰 페이지를 `갤러리`로 부를지 `리뷰`로 부를지 메뉴명 정리

## 5. 확정 사항과 추정 사항 구분

- [확정] HTML/CSS 파일 기준으로 홈, 네일, 패디, 이달의 아트, 케어, 리뷰, 매장 소개 페이지가 구현되어 있다.
- [확정] 외부 연결은 네이버 예약, 카카오톡 상담, 네이버 블로그 중심으로 구성되어 있다.
- [확정] PC 원본 구조와 별도의 모바일 화면을 함께 제공한다.
- [이력 확인] 모바일 레이아웃 추가, 글꼴 통일, 중복 제목 제거 등의 보완 작업이 반영되어 있다.
- [확인 필요] 케어 페이지의 장기 유지 여부와 운영 문구의 최종 승인 여부는 아직 문서상 확정할 수 없다.
