# 쵸코네일 삼송점 카테고리 페이지

업로드한 엑셀 파일의 `사진목록` 탭을 기준으로 생성한 HTML 파일입니다.

## 포함 파일
- gallery.html: 전체 갤러리
- gel-nail.html: 젤네일
- monthly-art.html: 이달의 아트
- pedi.html: 패디
- care.html: 케어
- shop.html: 매장
- category-style.css: 카테고리 페이지 공통 스타일

## 이미지 경로
HTML은 아래 경로의 이미지를 사용하도록 되어 있습니다.

```text
reference/images/파일명
```

따라서 이 파일들을 `C:\Users\mydun\Desktop\choco-nail-homepage` 폴더에 복사하면,
현재 말씀하신 이미지 폴더를 그대로 참조합니다.

## 적용 방법
1. 압축을 풉니다.
2. 압축 안의 HTML/CSS 파일을 `C:\Users\mydun\Desktop\choco-nail-homepage` 폴더에 복사합니다.
3. `gallery.html`을 더블클릭해서 확인합니다.
4. 기존 index.html에 연결하려면 메뉴나 버튼에 `gallery.html` 링크를 추가합니다.
