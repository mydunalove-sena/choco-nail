# 쵸코네일 덕양삼송점 홈페이지 v1

## 1. 프로젝트 소개

쵸코네일 덕양삼송점의 서비스, 시술 이미지, 리뷰 안내, 매장 소개와 상담·예약 경로를 제공하는 정적 홈페이지입니다.

PC 원본 이미지형 랜딩 화면을 보존하면서 모바일 전용 화면과 서비스별 모바일 레이아웃을 보완한 v1 버전입니다. 완성된 웹사이트를 기준으로 역기획 문서 8개를 정리한 개인 프로젝트입니다.

공식 프로젝트 표기는 `쵸코네일 덕양삼송점`이지만, 현재 v1 화면 코드에는 주로 `쵸코네일 삼송점`이 표시됩니다. 실제 화면 상호명 통일 여부는 확인이 필요합니다.

## 2. 배포 주소

- 웹사이트: https://mydunalove-sena.github.io/choco-nail/
- GitHub: https://github.com/mydunalove-sena/choco-nail

## 3. 주요 페이지

| 페이지 | 역할 |
|---|---|
| `index.html` | PC 원본 이미지형 홈과 모바일 전용 홈 |
| `gel-nail.html` | 젤네일 이미지 카드와 대표 가격 안내 |
| `pedi.html` | 페디 이미지 카드와 대표 가격 안내 |
| `monthly-art.html` | 이달의 아트 이미지 카드 |
| `care.html` | 케어 소개, 메뉴, 추천 대상, 진행 순서와 안내사항 |
| `gallery.html` | 내부 리뷰 안내 페이지와 네이버 리뷰 이동 |
| `shop.html` | 매장 소개 포스터 페이지 |

`gallery.html`은 파일명은 gallery이지만 현재 화면 명칭과 역할은 `리뷰`입니다. `care.html`은 구현되어 있으나 계속 운영할지는 매장주 협의 대기 항목입니다.

## 4. v1 구조 특징

- PC 홈은 `images/final-design.png` 위에 투명 hotspot 링크를 배치한 이미지형 랜딩 구조입니다.
- 760px 이하에서는 PC 홈을 숨기고 별도의 `mobile-home`을 표시합니다.
- 서비스별 개별 HTML 페이지 중심으로 구성되어 있습니다.
- 하위 페이지는 PC `category-nav`와 모바일 `details`/`summary` 메뉴를 제공합니다.
- 모바일 홈의 서비스 메뉴에는 네일, 이달의 아트, 페디, 케어 링크를 제공합니다.
- 모바일 홈에는 리뷰와 매장 소개 직접 링크가 없습니다.

## 5. 주요 기능

- PC 투명 hotspot 내비게이션
- 모바일 홈 주요 외부 링크
- 모바일 홈 서비스 메뉴
- 하위 페이지 PC 내비게이션
- 하위 페이지 모바일 `details` 메뉴
- 현재 페이지 `active` 및 `aria-current` 표시
- 서비스 이미지 카드
- 리뷰 포스터 투명 링크
- 네이버 장소 및 리뷰 이동
- 카카오톡 상담
- 네이버 블로그 이동
- PC·모바일 반응형 전환

전화 링크와 이미지 오류 fallback은 현재 구현되어 있지 않으며, 별도 JavaScript는 사용하지 않습니다.

예약 버튼은 네이버 장소 기본 URL을 사용하며, 실제 예약 전용 화면 연결 여부는 확인이 필요합니다.

## 7. 반응형 구성

- 홈 PC·모바일 전환: 760px
- 하위 페이지 PC·모바일 전환: 760px
- PC 헤더 재배치: 980px 이하
- 카드 2열 전환: 900px 이하
- 카드 1열 전환: 560px 이하
- 소형 모바일 추가 조정: 370px 또는 374px 이하
- 검수 기준 화면 폭: 360px, 390px, 412px, 560px, 760px, 768px, 980px, 1280px 이상

정적 코드 검수는 완료했으나, 이번 역기획 문서 작성 과정에서는 브라우저 에뮬레이션과 실제 기기 검수를 별도로 수행하지 않았습니다.
